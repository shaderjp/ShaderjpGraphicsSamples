# Geometry Lab：高密度形状とクラスタの教材用アセット

発展20〜23はこのリポジトリ用に制作したGeometry Labを使用します。[Blender正本と再生成手順](../../SourceArt/Blender/GeometryLab/README.md)、[配布Manifest](../../Assets/Models/GeometryLab/Manifest.json)を参照してください。

| 形状 | 役割 |
|---|---|
| レリーフ付き彫刻 | 不規則メッシュの空間クラスタ分割と通常BLAS比較 |
| 薄板彫刻 | 固定トポロジーでのGPU変形とテンプレート再利用 |
| 規則タイル | 分割率2・4・8、変位、隣接境界の接続 |
| 可動パネル群 | 4×4インスタンスを1partitionとする疎なTransform更新 |

頂点の位置、法線、UV、接線を保持したまま、meshoptimizer v1.3の`meshopt_buildMeshletsSpatial`で最大256頂点・32〜128三角形に分割し、`meshopt_optimizeMeshlet`でクラスタ内部を最適化します。通常BLASにも同じ最終三角形列を渡します。既存Mesh Shaderサンプルの64頂点・96三角形という設定は変更しません。

規則タイルには33種類のトポロジーがあります。2分割・4分割は各辺の接続フラグ16通り、8分割は1通りです。隣接タイルとの細かさの差を最大1段に制限し、粗い側の境界セルを中心点のfanで分割します。共有境界は同じワールド座標で変位を評価します。

これらは自作MITデータです。NVIDIAのサンプルアセットは配布物に含みません。

実演用の柱・梁は台座メッシュのインスタンスから構成します。配置と、PTLASのStress全域を覆う床の拡大はCPU側で適用します。原本のメッシュと実演シーンの配置を区別しています。
